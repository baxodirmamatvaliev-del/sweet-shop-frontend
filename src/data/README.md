# Morrow Coffee menu assets

`morrow-menu.json` contains 20 selected coffee variants with Morrow Coffee cup branding. The selection covers classic iced coffees, hot Americano and Latte, decaf Americano, and seasonal lattes. It is a portfolio selection, not an official popularity ranking.

All 20 photos were individually edited with built-in imagegen using the existing Morrow Coffee wordmark and cup icon. The final WebP assets are in `public/img/morrow-coffee/menu/`, at most 640px per edge, totaling 363 KiB. See `morrow-branding-prompt.md` for the edit prompt.

The original 161-item import was reduced to these 20; the other 141 imported menu photos were removed from the project. Source names, original image URLs, source category IDs, and source page links remain in the JSON for traceability. Original selected photos were backed up outside the project during editing.

Source: https://mega-mgccoffee.com/menu/?menu_category1=1&menu_category2=1
Retrieved on 2026-10-19. HOT and ICE variants remain separate entries.

These are local catalog entries, not backend products. Local IDs must not be submitted to the order API. The source does not supply prices; match entries to backend product IDs and KRW prices before enabling purchase. No backend data was changed.
